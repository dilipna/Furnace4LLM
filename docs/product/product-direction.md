# Furnace product direction

Owner-confirmed direction: infrastructure for model researchers, with the current
cream-and-green visual theme. The document assistant is an example application.

1. Download Furnace, inspect/connect a model project and receive a free infrastructure
   starter kit.
2. Use the existing local serving, security controls, evaluations, monitoring, logs
   and recovery tools for supported models.
3. A proposed $20/month service would have Furnace operate that infrastructure.
   Initial demonstrations cover one or two models; expansion follows funding.

The free local application and kit export exist. Hosted provisioning, billing and
service commitments do not. Inspection reads bounded metadata without loading a
model; it does not prove that the model or every architecture works. Inference needs
Docker and a compatible recipe/server/adapter with explicit execution approvals.

## Application entry points

- `/`: researcher Studio; project inspection, assessment, preferences and kit export.
- `/model`: operate a pinned local model or connect a compatible server/adapter.
- `/advanced`: compatible alias for Studio.
- `/examples/documents`: document example over the same local model infrastructure.

The document features and all historical evaluation records are retained. Their
recordings identify their original source and are not footage of this updated
front door. The original November 24 walkthrough and independent branches are unchanged.

## Verification

The free kit and same-project model handoff have an executed
[round-trip verification](researcher-kit-handoff.md), separate from real-model trials.

Exercise project inspection and kit download through the real UI/API, without Docker.
Check that model operations still require explicit consent and suitable prerequisites.
Check that the document example remains reachable, preserves its route after session
bootstrap, and retains its existing safety and privacy tests.

No main merge, release publication, deployment, billing or new hosted infrastructure
is part of this repositioning.
