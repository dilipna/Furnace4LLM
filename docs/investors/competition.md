# Competition — primary-source review

Reviewed November 27, 2026. Documented capabilities, not hands-on competitor tests.
Unknown does not mean absent. No feature-exclusivity or performance-superiority claim.

| Alternative | Its documentation shows | Stronger choice for | Furnace hypothesis / gap |
| --- | --- | --- | --- |
| [Modal](https://modal.com/pricing) | Metered CPU/GPU, metrics/logs and concurrency plans | Elastic hosted compute | Local ownership/evidence workflow; Furnace hosting is only a proposal. |
| [Replicate](https://replicate.com/docs) | APIs, custom deployments and model-building guides | Hosted catalog/custom packaging ecosystem | Personal local onboarding; custom model packaging is not unique. |
| [HF Inference Endpoints](https://huggingface.co/docs/inference-endpoints/index) | Dedicated endpoints, custom containers, logs, metrics, autoscaling | Hub integration and managed deployment | Researcher-controlled local operation, not exclusive architecture support. |
| [Baseten](https://docs.baseten.co/overview) | Dedicated logs, metrics, autoscaling and Truss | Managed serving/observability tooling | Smaller local workflow; no equivalent hosted scale claim. |
| [Ollama](https://docs.ollama.com/) | Computer-local and cloud models, application APIs | Model/app ecosystem | Lifecycle evaluations and recovery evidence must justify switching. |
| [LM Studio](https://lmstudio.ai/docs/app) | Local model app, document chat, presets, import and parallel requests | Established local model/document experience | Researcher operating workflow; document chat is not novel. |
| [EleutherAI harness](https://github.com/EleutherAI/lm-evaluation-harness) | Benchmarks, local/API backends, custom tasks | Research benchmark breadth/comparability | Lifecycle around evaluation; small rule suites do not replace it. |

Competitors can add adjacent features. The opportunity is a workflow/customer-service
hypothesis in an occupied market. Later integration with evaluation tools may make
sense; none is promised. No independent competitor security/performance test was run.
