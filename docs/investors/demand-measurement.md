# Demand measurement — proposal only

No tracking, form, analytics or endpoint without owner approval. No telemetry in
Studio's inference path. Local operation must not require a waitlist.

| Proposed signal | Collection if approved | Limits |
| --- | --- | --- |
| GitHub Release downloads and stars | Dated public aggregate snapshots with URL/time | Downloads are not unique installs; stars are not payment demand. No device IDs. |
| Optional managed-plan waitlist with $20/month visible | Email, compute ownership, optional model family, separately opt-in | Interest, not revenue; distinct from the free product. |
| Design partners | Consented aliases/session ledger, tasks, repeat usage and assistance | Invited, completed, paid and LOI are separate states. |
| Folder to first evaluated service | Facilitator timestamps, exact identities and prerequisite/cache/build/download state | Manual consented observation; preserve failed/incomplete sessions. |
