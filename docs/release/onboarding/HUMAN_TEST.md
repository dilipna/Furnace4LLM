# Independent usability test — no observations collected

Participants: one nontechnical person and one developer unfamiliar with Furnace. Give
each the same extracted preview and prerequisite sheet. Prepare local Linux Docker only
if the participant will run the fixture. Allow roughly 15 minutes independently; do not
coach. Ask them to think aloud. Record actions, exact words, confusion and assistance
only after participation. Automated browser observations do not fill these cells.

| Task | Nontechnical participant: observations/assistance | Unfamiliar developer: observations/assistance |
| --- | --- | --- |
| Explain Furnace's purpose and who it is for | | |
| Complete the guided example through an executed fixture check and kit export | | |
| Identify whether the shown values are recorded or newly executed, and whether any model ran | | |
| Explain the exact-check verdict, unscored case, reference and limitations | | |
| Find the correct next step and prerequisites for evaluating their own application/model | | |

Afterward ask what they expected, where they hesitated and what evidence they would need
before trusting a result. Report task completion separately from comprehension; do not
convert assistance or skipped execution into success. No pass rate or feedback exists yet.
