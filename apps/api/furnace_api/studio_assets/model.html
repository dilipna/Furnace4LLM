Connection settings

2. Describe your server

No Docker is required for this connector. A running, unauthenticated OpenAI-compatible text-chat server is required. Only http://127.0.0.1:PORT/v1 is accepted; no remote hosts, credentials, redirects or environment proxies. Saving makes no network request.

3. Confirm and connect

The connection check reads the server's model list. It does not establish inference or model quality. Reconnect after changing the contract, cases, preferences or connection, or restarting Studio.

Disconnecting never stops or uninstalls your external server. Furnace cannot cancel generation already running there. It bounds its own connection and stops issuing more requests.

Evaluate saved cases

Cases come from Workspace → Checks. Their fixture results are separate. Exact string equality is not semantic answer quality. Descriptive expectations stay unscored. Token-limit termination is incomplete, even if its text matches. The batch stops on a request failure or after 30 seconds; missing cases never pass.

Durations are client-observed non-streaming HTTP round trips, not TTFT or a model speedup. No baseline comparison, semantic judge, session-state isolation or architecture certification is implied.
