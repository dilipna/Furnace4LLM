Let Furnace run a pinned model

Furnace-operated server

Furnace pulls a pinned server image by digest, verifies downloaded weights by SHA-256, then runs a non-root model container on an internal Docker network with memory limits and a per-launch key. Requires local Docker with Linux containers; NVIDIA execution also needs GPU support in Docker. Cloud hosting and billing remain inactive.

Connection settings

Or describe a server you operate
No Docker is required for this path. A running, unauthenticated OpenAI-compatible text-chat server is required. Only http://127.0.0.1:PORT/v1 is accepted; no remote hosts, credentials, redirects or environment proxies. Saving makes no network request.




Confirm and connect
The connection check reads the server's model list. It does not establish inference or model quality. Reconnect after changing the contract, cases, preferences or connection, or restarting Studio.
Disconnecting never stops or uninstalls a server you operate; stop a Furnace-operated server with Stop server. Furnace cannot cancel generation already running in a server. It bounds its own connection and stops issuing more requests.

Run saved checks
Evaluate saved cases
Cases come from Workspace → Checks or the reference suite. Their fixture results are separate. Each case is checked by its rule: exact text, normalized text, required text, a pattern, the answer number, exactly one choice or JSON fields. Rule checks are not human quality judgements. Descriptive expectations stay unscored. Token-limit termination is incomplete, even if its text matches. The batch stops on a request failure or when its evaluation budget runs out; missing cases never pass.
Durations are client-observed non-streaming HTTP round trips, not TTFT or a model speedup. No baseline comparison, semantic judge or architecture certification is implied.

Attempt history
Review the last ten endpoint evaluation attempts, including failures and interruptions. Retrying executes cases again and retains the earlier attempt. Older attempts expire in start order; export the kit to keep a copy. Configuration labels describe saved inputs, not independently verified model weights.
History stores request IDs, statuses, durations and output hashes, without raw prompts or outputs. Prior case text is not retained here. A completed attempt can contain failed or unscored checks; these are not quality scores. Removing the project removes its retained history.
