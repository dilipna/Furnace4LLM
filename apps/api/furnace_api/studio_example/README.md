# Infrastructure walkthrough

This is a metadata-only project bundled with Furnace Studio. It is not a research
model. No learned parameters, checkpoint files or model loading code are included.

The separately authored framework fixture runs only after explicit local Docker
consent. It returns `framework:` followed by uppercased input. Exact-output checks
exercise the worker protocol; descriptive expectations are unscored. Neither result
establishes model quality or architecture compatibility.
