What this establishes

For this controlled workload, prefix layout changed cached-token reuse and streamed latency. The same FurnaceBench streaming client measures every condition. The mitigation preserved the paired metadata and queries.

Limits: one small model, one laptop GPU, synthetic inputs, concurrency one, short fixed outputs. No answer-quality evaluation, customer adoption, production speed guarantee, or Qwen3-4B result. A cache-off run reached 3072.90 ms p95; no outliers were removed. Consistency checks are not independent authentication of where measurements originated.
